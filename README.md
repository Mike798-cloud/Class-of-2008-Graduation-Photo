# 《2008届毕业照》网页解谜

双击 `index.html` 即可本地试玩，也可以直接把整个文件夹部署到 GitHub Pages / Cloudflare Pages 等静态托管。

## 核心交互
- 二维写实固定视角场景，不使用电脑桌面模拟作为主载体。
- 所有场景热点默认不可见；鼠标经过不高亮、不改变鼠标样式。
- 照片对照、实体线索、暗房显影、电话证词、线索册、多结局。
- 本地自动存档 `localStorage`，标题页与菜单均可“重置案件”。
- 三级提示只在玩家主动点击提示后出现。

## 付款入口配置
当前成品保留了结局后的 ¥1 / ¥3 / ¥6 自愿支持入口，但**没有写入任何真实收款信息**。
如果需要接入你自己的二维码：
1. 将微信/支付宝二维码图片放到 `assets/img/`；
2. 修改 `app.js` 中 `support(amount)` 函数，把当前说明卡片替换为对应二维码 `<img>`；
3. 付款仍应保持自愿，不应锁结局或关键内容。

## 部署
项目是纯静态 HTML/CSS/JS，不需要 Node、npm 或服务器运行时。

Windows 用户可双击 `build_release.bat`：它会检查核心文件；若电脑安装了 Node.js，会额外执行 `node --check app.js`；随后在根目录生成 `release\2008届毕业照` 部署目录以及 `2008届毕业照-release.zip`。

发布包只包含实际运行需要的 `assets/img`（以及存在内容时的 `assets/audio`），不会把原始摄影素材或测试脚本一起部署。
